1. Mô tả các tập tin nộp

- main.ipynb
  Notebook trình bày các bước tiền xử lý dữ liệu tài chính sử dụng dữ liệu từ Yahoo Finance (yfinance), bao gồm:
  + Thu thập dữ liệu
  + Làm sạch dữ liệu
  + Xử lý dữ liệu thiếu
  + Tính toán lợi nhuận (Simple Return, Log Return)
  + Điều chỉnh lạm phát bằng CPI
  + Trực quan hóa dữ liệu
  + Tính toán độ biến động (Volatility)

- bars.ipynb
  Notebook trình bày cách xây dựng các loại Event-Based Bars từ dữ liệu giao dịch, bao gồm:
  + Tick Bar
  + Volume Bar
  + Dollar Bar
  + Gom nhóm dữ liệu theo thời gian
  + So sánh giữa Time Bars và Event-Based Bars

2. Thư mục dữ liệu (data)

- yf_data_processed.csv
  Dữ liệu tài chính đã qua tiền xử lý từ Yahoo Finance.

- computing_comparison.csv
  Tập dữ liệu dùng để so sánh các phương pháp tính toán và xử lý dữ liệu.
